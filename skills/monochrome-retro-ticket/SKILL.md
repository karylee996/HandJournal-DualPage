# Monochrome Retro Travel Ticket

## 1. Trigger / 适用场景

当用户上传一张照片，并希望将其制作成：

- 复古旅行票根
- 纪念券 / 车票 / 电影票式旅行卡片
- 单色木刻 / Risograph 风格票券
- 带地点、时间、天气与旅行描述的信息型纪念票根

时使用本 Skill。

如果用户提供地点、日期、具体时间或自定义描述，必须优先采用用户信息。

---

## 2. Input Interpretation

将用户上传的照片作为唯一真实视觉来源，用于判断：

- 画面主体
- 建筑 / 地标 / 人物 / 自然景观
- 场景空间关系
- 地点线索
- 时间氛围
- 天气
- 主色调

可选用户补充字段：

- 地点：未知可留空
- 拍摄日期：未知可留空
- 具体时间：未知可留空
- 自定义描述：未知则根据画面生成

不得仅凭常识擅自补全用户未提供、且画面无法确认的信息。

---

## 3. Canvas & Ticket Structure

最终生成：

**竖版 9:16 复古旅行纪念票根。**

必须满足：

- 票根完整居中
- 四周完整可见
- 四边保留连续、整齐的半圆形齿孔或票券冲孔
- 不裁切票根边缘
- 不让任何齿孔超出画布
- 票根主体周围保留适量留白

版面比例建议：

- 上方约 60%：主题插画区
- 下方约 40%：旅行信息与文字排版区

如果构图需要，可以在不破坏 9:16 与票根完整性的前提下进行小幅调整，但整体仍需保持“上图下文”的票券逻辑。

---

# 4. Main Illustration / 主题插画

分析照片，识别最具代表性的主体，只保留能够表达照片主题和地点记忆的核心元素。

优先保留：

1. 最具辨识度的主体轮廓
2. 地标建筑或主要人物
3. 与主体相关的关键环境
4. 少量能够帮助识别地点的背景结构
5. 符合原图的天空、植物或地面关系

主动删减：

- 杂乱背景
- 无关路人
- 多余车辆
- 广告牌
- 杂乱招牌
- 不重要的小型物体
- 重复建筑
- 过度复杂的城市细节

目标：

**比原照片更简洁，但仍能一眼认出原照片的主体与场景。**

---

## 5. Source Fidelity / 原图忠实度

必须保持：

- 原照片主体的基本外形
- 主要比例关系
- 原始视角
- 核心构图关系
- 地点辨识度
- 主体之间的空间关系

不得：

- 将地点改成其他城市
- 添加照片中不存在的著名建筑
- 添加虚构故事元素
- 随意改变建筑结构
- 随意改变人物身份或服装主题
- 将真实场景改造成完全不同的景观

允许：

- 简化
- 概括
- 删除无关细节
- 抽象明暗
- 改变视觉媒介与印刷质感

---

## 6. Illustration Style / 插画风格

将照片转换为：

**简洁复古木刻版画 + 手工线描 + 丝网印刷 + Risograph 孔版印刷的混合风格。**

视觉特征：

- 粗细不均的手绘轮廓
- 木刻式线条
- 适度排线
- 网点
- 大色块
- 纸张留白
- 轻微套印感
- 轻微油墨不均
- 克制的旧纸颗粒
- 手工印刷触感

明暗表现仅通过：

- 同色排线密度
- 同色网点密度
- 同色叠印
- 米白纸张留白

避免：

- 照片级写实
- 3D 渲染
- 光滑塑料感
- 数字矢量过于干净的边缘
- 复杂真实阴影
- 过度精细刻画

---

# 7. Strict Monochrome Rule / 严格单色规则

整张票根必须使用**严格单色印刷**。

自动分析照片整体色彩，提取最具代表性的主色相，并将该颜色适当加深为适合印刷、具有足够对比度的单一油墨色。

所有以下元素必须使用同一种油墨色：

- 插画
- 文字
- 边框
- 分隔线
- 图标
- 印章
- 装饰
- 阴影纹理

整张画面只能包含：

1. 一种从原照片主色调提取并加深后的单色油墨
2. 温暖米白色纸张底色

禁止：

- 第二种彩色油墨
- 黑色作为额外描边色
- 红 + 蓝、红 + 黑、绿 + 黑等双色组合
- 彩色渐变
- 彩虹色
- 霓虹色
- 独立点缀色

如果原照片主色偏浅：

- 保留相同色相
- 将颜色适当加深
- 提高印刷可读性

如果原照片接近黑白：

- 使用深灰黑色单色油墨

不同深浅只能通过同色网点、排线、叠印与纸张留白产生。

---

# 8. Paper & Print Texture

纸张：

- 温暖米白色
- 轻微泛黄
- 细微纸纤维
- 轻微旧纸颗粒
- 不脏
- 不过度做旧

印刷：

- 微弱油墨不均
- 轻微孔版颗粒
- 轻微木刻质感
- 边缘略有手工印刷的不完美

整体应像真实收藏的旧旅行票券，而不是现代数字海报。

---

# 9. Information Extraction / 信息生成

根据原照片与用户提供的信息，为票根生成：

1. 简短的中文、日文或当地语言标题
2. 对应英文副标题
3. 国家、城市或区域名称
4. 照片中的主要地标或主体
5. 拍摄日期
6. 拍摄时间或时间段
7. 天气与现场氛围
8. 一段简短的中文 / 日文旅行描述
9. 一句简洁英文旅行描述

语言选择原则：

- 日本地点：可优先日文 + 英文
- 中文地区：可优先中文 + 英文
- 其他国家：可使用当地语言 / 英文，必要时辅以中文
- 用户有明确文字要求时，优先用户要求

---

## 10. Suggested Typography Structure

推荐结构：

[ENGLISH TITLE]
[CITY • COUNTRY]

LANDMARK : [主要地标或主体]
AREA : [区域或场景]

WEATHER : [天气状态]
DATE : [真实日期或 —]

[根据画面生成的一句中文 / 日文描述]
[对应的简洁英文描述]

可使用：

- 圆点虚线
- 打孔式分隔线
- 老式车票信息栏
- 电影票式层级
- 旅行纪念章

文字排版必须：

- 层级清晰
- 留白舒适
- 对齐整齐
- 不拥挤
- 不喧宾夺主
- 有收藏票券感

---

## 11. Decorative Icons

可根据照片主题加入 2–3 个小型单色剪影图标，例如：

- 地标小剪影
- 树木
- 山峰
- 海浪
- 神社 / 寺庙屋顶
- 太阳 / 云
- 简洁旅行印章

必须：

- 与原图主题相关
- 使用相同单色油墨
- 尺寸小
- 不抢主体

不得加入原照片中完全无关的著名地标。

# 12. Information Accuracy / 信息准确性

## 用户提供信息时

优先采用用户填写的：

- 地点
- 日期
- 时间
- 描述

必须尽量保证文字与用户输入一致。

## 用户未提供信息时

### 地点

只能根据照片中**明确可辨认**的：

- 地标
- 招牌
- 文字
- 建筑特征

进行判断。

如果不能确定具体城市：

- 不虚构
- 可写 `TRAVEL MEMORY`
- 或将地点留空

### 日期

如果无法从图片或用户信息确认：

`DATE : —`

不得自行编造日期。

### 时间

无法确认具体钟点时，只根据画面判断：

- DAYTIME
- SUNSET
- EVENING
- NIGHTTIME

不得虚构精确时间。

### 天气

只根据画面可见状态选择：

- SUNNY
- CLOUDY
- RAINY
- MISTY
- SNOWY

不确定时使用更保守的描述。

### 描述

仅描述画面中真实可见的：

- 主体
- 光线
- 天气
- 城市 / 自然环境
- 现场氛围

不得编造：

- 人物关系
- 旅行故事
- 历史事件
- 情绪剧情
- 未发生的行为

---

# 13. Text Reliability

所有文字必须尽量做到：

- 完整
- 清晰
- 拼写正确
- 不重复
- 无乱码
- 无无意义字符

如果图像模型难以稳定生成较长文字：

优先减少文字数量，而不是生成乱码。

信息层级优先级：

1. 主标题
2. 英文标题
3. 城市 / 国家
4. LANDMARK
5. TIME / WEATHER / DATE
6. 简短描述

# 18. Master Generation Prompt

将用户上传的原始照片转换为一张完整居中的竖版 9:16 复古旅行纪念票根。四周保留连续、整齐、完整可见的半圆形齿孔或票券冲孔，绝不裁切票根边缘。上方约 60% 为主题插画区，下方约 40% 为旅行信息排版区。

严格依据原照片提取最具代表性的主体、建筑、人物、自然景观或地标，仅保留能够表达照片主题和地点记忆的核心元素。删减杂乱背景、无关路人、车辆、广告、重复建筑和不重要的小物体，使画面比原照片更加简洁，但必须保留主体外形特征、原始视角、核心构图关系、空间关系与场景辨识度。不得将地点改成其他城市，不得加入照片中不存在的著名建筑、人物关系或故事元素。

将主体转换为简洁的复古木刻版画、手工线描、丝网印刷与 Risograph 孔版印刷混合风格。使用粗细不均的手绘轮廓、排线、网点、大色块与纸张留白表现明暗，具有轻微油墨不均、轻微套印感、旧纸纤维和克制的手工印刷颗粒。不要照片写实，不要 3D，不要数字矢量过度光滑，不要复杂真实阴影，不要过度精细。

整张票根必须严格采用单色印刷。自动分析原照片整体色彩，提取最具有代表性的主色相，并将其适当加深为适合印刷、对比充分的一种单一油墨色。所有插画、文字、边框、分隔线、图标、装饰和印章全部使用同一种油墨。画面只能包含这一种深色油墨与温暖米白色纸张底色。所有明暗差异只能通过同色网点密度、排线、叠印和纸张留白表现。绝不加入第二种彩色油墨、独立黑色描边、渐变、霓虹色或额外点缀色。如果原照片接近黑白，则使用深灰黑色单色油墨。

根据原照片中可以确认的信息，为票根自动生成简短的当地语言 / 中文标题、英文副标题、城市或区域、主要地标或主体、日期、时间段、天气、一句简短当地语言 / 中文旅行描述和一句简洁英文描述。排版参考复古电影票、火车票和旅行纪念券，使用圆点虚线或打孔式分隔线，层级清晰、留白舒适、整齐专业。可加入 2–3 个与照片主题直接相关的小型单色剪影图标，但不要喧宾夺主。

优先使用用户提供的地点、日期、时间和描述，并保证内容一致。如果用户未提供地点，只能根据照片中明确可辨认的地标、招牌或文字判断；不能确认时使用 TRAVEL MEMORY 或留空。日期不能确认时写 `DATE : —`。无法确认具体时间时，仅使用 DAYTIME、SUNSET、EVENING 或 NIGHTTIME，不虚构精确钟点。天气必须与照片可见状态一致。文字描述只描写真实可见的主体、光线、天气与现场氛围，不编造旅行故事或历史情节。

整体呈现日系复古旅行纪念品、旧电影票、火车票、木刻插画与单色 Risograph 孔版印刷质感。画面简洁、克制、有设计感、有收藏价值，既保留原照片的地点记忆，又形成统一的复古票根视觉语言。所有文字尽量完整、清晰、拼写正确，不出现乱码、重复文字、无意义字符、二维码、条形码或品牌水印。
